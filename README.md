# 💱 Conversor de Monedas en Java

Aplicación desarrollada en **Java** que permite realizar conversiones entre distintas monedas utilizando una **API de tasas de cambio en tiempo real**.

## 🚀 Características

- Conversión de monedas en tiempo real
- Interfaz por consola
- Uso de una API externa confiable
- Proyecto desarrollado en **IntelliJ IDEA**

## 🛠️ Tecnologías Utilizadas

- **Java**
- **IntelliJ IDEA**
- **ExchangeRate API**  
  🔗 https://www.exchangerate-api.com

## 🌍 Conversiones Disponibles

La aplicación permite realizar las siguientes conversiones:

1. 💵 Dólar (USD) → Peso Argentino (ARS)  
2. 💰 Peso Argentino (ARS) → Dólar (USD)  
3. 💵 Dólar (USD) → Real Brasileño (BRL)  
4. 💰 Real Brasileño (BRL) → Dólar (USD)  
5. 💵 Dólar (USD) → Peso Colombiano (COP)  
6. 💰 Peso Colombiano (COP) → Dólar (USD)  

## ⚙️ Funcionamiento

- El usuario selecciona el tipo de conversión
- Ingresa el monto a convertir
- La aplicación consulta la API para obtener la tasa de cambio actual
- Se muestra el resultado de la conversión
